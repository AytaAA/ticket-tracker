# Code + security review — 2026-11-24

Two independent reviews of the whole codebase (`backend/app`, `frontend/src`, `scripts`, `docker-compose.yml`,
`frontend/nginx.conf`): `/code-review` (high) and a read-only security reviewer (the built-in `/security-review`
needs a git remote, which this repo doesn't have).

## Security review

No high-severity issues. Verified OK: session fixation, expiry, logout, cookie flags, login timing/enumeration,
verification tokens (hash only, single-use, 24 h, POST from the SPA), auth on every non-public endpoint, comment
ownership (no IDOR), SQL injection (ORM only), mass assignment (`extra="forbid"`), XSS (no raw HTML), open
redirect, SMTP header injection, error leaks, secrets in repo and git history, no seed data.
